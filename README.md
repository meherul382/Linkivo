# Linkivo

Personal URL Shortener built with Next.js + Supabase.

## Planned modules
- Short link creation
- Custom aliases
- Redirect handling
- Link management
- Click analytics
- Supabase persistence
- VPS migration support

## Environment
Create `.env.local` later with:
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

## Deployment
Vercel is connected to the `main` branch.
